# Support

This community preview is provided without guaranteed support or uptime.

Before reporting a problem:

1. Reproduce it in research mode if possible.
2. Run `.\verify.ps1` from a source checkout.
3. Export **File → Export redacted diagnostics** and inspect the JSON yourself.
4. Remove any personal, financial, immigration, tax, credential, account, and order information.

A public issue tracker URL has not yet been selected. Public distribution is blocked until the maintainer adds a monitored support destination here and to the application About dialog.

Broker account, authentication, order execution, settlement, or provider outage questions belong with the broker. Tax, legal, immigration, and financial questions belong with qualified professionals.
