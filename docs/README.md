# GRANDE Alpha documentation

Start with [Quickstart](QUICKSTART.md) for a local research run, or [Windows installation](WINDOWS_INSTALLATION.md) for setup. The [CLI reference](CLI.md) covers command-line use.

> [!IMPORTANT]
> Passing research checks does not establish profitability or authorize an order. Broker access,
> account eligibility, evidence, risk limits, and execution authority are separate requirements.
