# GRANDE Alpha documentation

This index separates the durable product contract, current operating documentation, and dated
research/audit records. Start with the path that matches what you are trying to do.

> [!IMPORTANT]
> A passing check, replay, or evidence certificate does not promise profit. Real-order capability,
> a bounded session grant, and broker acceptance are separate conditions.
